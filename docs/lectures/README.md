# 📚 สารบัญเอกสารประกอบการสอนวิชา Web (Course Lecture Materials)

เอกสารสไลด์และใบงานทั้งหมดของอาจารย์ผู้สอน ถูกจัดเก็บรวบรวมไว้ที่นี่อย่างเป็นระเบียบ:

---

### 🎨 1. หมวดพื้นฐานเว็บและสไตล์ (Frontend Fundamentals)
* `Week1.pdf` — ภาพรวมและการทำงานของ Web
* `Week2.pdf` — โครงสร้าง HTML พื้นฐาน
* `Week3.pdf` — รูปแบบแท็กและการจัดหน้า
* `Week4.pdf` — CSS พื้นฐานและการกำหนดรูปแบบ
* `Week5.pdf` — CSS Box Model และ Layout
* `Week6_flex.pdf` — การจัดเลย์เอาต์ด้วย CSS Flexbox
* `Week6Grid.pdf` — การจัดเลย์เอาต์ขั้นสูงด้วย CSS Grid
* `week7.pdf` — เทคนิค Responsive Web Design

---

### ⚙️ 2. หมวดการเขียนโปรแกรม JavaScript (JavaScript Programming)
* `Week10 javascript_basic.pdf` — พื้นฐานภาษา JavaScript
* `Week10 Intermediate Javascript.pdf` — DOM Manipulation และ Event Handling
* `week12 Advanced Javascript.pdf` — Asynchronous JavaScript (Promises, async/await)
* `การใช้ JSON และ JavaScript Object.pdf` — การจัดการข้อมูล JSON และ Object

---

### 🖥️ 3. หมวดเซิร์ฟเวอร์และฐานข้อมูล (Backend, Node.js & PostgreSQL)
* `week13 backend web app.pdf` — พื้นฐาน Backend Web Architecture
* `week14 express.pdf` — การสร้าง Web Server ด้วย Express.js และ Routing
* `EJS.pdf` — การทำ Server-Side Rendering ด้วย EJS Template Engine
* `Session.pdf` — การจัดการ Session และการยืนยันตัวตน (Authentication)
* `เอกสารประกอบการสอน_psql_และการจัดการสิทธิ์.pdf` — ฐานข้อมูล PostgreSQL, คําสั่ง SQL, และการจัดการสิทธิ์ด้วยตาราง ACL

---

### 📊 4. หมวดใบงานขั้นสูง (Advanced Lab Sheets)
* `ใบงาน การใช้งาน Node ส่งออกไฟล์ csv และ pdf.pdf` — การ Export ข้อมูลออกมาเป็นไฟล์ CSV และ PDF
* `ใบงานการใช้ Node แสดงข้อมูลบนแผนภูมิ.pdf` — การดึงข้อมูลสรุปมาแสดงผลบน Dashboard กราฟและแผนภูมิ
