================================================================================
PostgreSQL & psql Command Reference Guide (ระบบ RoomReserve)
================================================================================

[ สาเหตุของ Error 3D000 ใน node src/app.js หรือ npm start ]
Error '3D000' (routine: InitPostgres) หมายถึง "Database does not exist" 
ฐานข้อมูล roomreserve_db ที่ระบุไว้ในไฟล์ .env ยังไม่ได้ถูกสร้างขึ้นมาใน PostgreSQL Server


--------------------------------------------------------------------------------
1. psql -h localhost -U postgres
--------------------------------------------------------------------------------
ประเภท: Terminal / Command Line
คำอธิบาย: ใช้สำหรับเชื่อมต่อเข้าสู่ฐานข้อมูล PostgreSQL ผ่านเครื่องมือ CLI (psql)
- -h localhost : กำหนด Host เครื่องปลายทาง (localhost คือเครื่องของเราเอง)
- -U postgres  : กำหนดชื่อ User ที่จะเข้าใช้งาน (postgres คือ default superuser)
เมื่อรันแล้วระบบจะถาม Password ของ user postgres (ค่าเริ่มต้นคือ postgres)


--------------------------------------------------------------------------------
2. \encoding UTF8
--------------------------------------------------------------------------------
ประเภท: psql Meta-command (พิมพ์ใน psql)
คำอธิบาย: ตั้งค่า Client Encoding ให้เป็น UTF-8 เพื่อรองรับภาษาไทยและอักขระพิเศษ
ป้องกันการแสดงผลเป็นภาษาต่างดาวหรือเครื่องหมายคำถาม (?) บน Windows Console


--------------------------------------------------------------------------------
3. \l (หรือ \list)
--------------------------------------------------------------------------------
ประเภท: psql Meta-command (พิมพ์ใน psql)
คำอธิบาย: แสดงรายชื่อ Database ทั้งหมดที่มีอยู่ใน PostgreSQL Server
รวมถึงบอก Owner, Encoding และ Access Privileges


--------------------------------------------------------------------------------
4. CREATE DATABASE roomreserve_db;
--------------------------------------------------------------------------------
ประเภท: SQL Query (ต้องมีเครื่องหมาย ; ปิดท้าย)
คำอธิบาย: สร้างฐานข้อมูลใหม่สำหรับระบบจองห้องประชุม RoomReserve
ตัวอย่าง:
  CREATE DATABASE roomreserve_db;


--------------------------------------------------------------------------------
5. DROP DATABASE roomreserve_db;
--------------------------------------------------------------------------------
ประเภท: SQL Query (ต้องมีเครื่องหมาย ; ปิดท้าย)
คำอธิบาย: ลบฐานข้อมูล roomreserve_db ทิ้งอย่างถาวร (กรณีต้องการล้างข้อมูลเพื่อเริ่มใหม่ทั้งหมด)
ข้อควรระวัง: ไม่สามารถลบ Database ที่ตัวเรากำลังเชื่อมต่ออยู่ได้ ต้องสลับไป DB อื่น (เช่น \c postgres) ก่อน
ตัวอย่าง:
  \c postgres
  DROP DATABASE roomreserve_db;


--------------------------------------------------------------------------------
6. \c roomreserve_db
--------------------------------------------------------------------------------
ประเภท: psql Meta-command (พิมพ์ใน psql)
คำอธิบาย: สลับ (Connect) ไปยัง Database roomreserve_db เพื่อทำงาน
ตัวอย่าง:
  \c roomreserve_db
ผลลัพธ์: จะเปลี่ยน prompt จาก postgres=# เป็น roomreserve_db=#


--------------------------------------------------------------------------------
7. \i database/schema.sql
--------------------------------------------------------------------------------
ประเภท: psql Meta-command (พิมพ์ใน psql)
คำอธิบาย: รันไฟล์ SQL Schema เพื่อสร้างตารางทั้งหมด, Dynamic ACL, btree_gist extension และ Foreign Keys
ตัวอย่าง:
  \i database/schema.sql
  (หรือถ้าอยู่นอกโฟลเดอร์ ให้ระบุ Path เช่น \i 'D:/Agents-System/web-project/database/schema.sql')


--------------------------------------------------------------------------------
8. \dt
--------------------------------------------------------------------------------
ประเภท: psql Meta-command (พิมพ์ใน psql)
คำอธิบาย: แสดงรายชื่อตาราง (Tables) ทั้งหมดใน Database roomreserve_db
ตารางที่จะปรากฏ:
  - roles               : ตารางบทบาท 4 บทบาทหลัก
  - permissions         : ตารางสิทธิ์การใช้งาน 14 สิทธิ์
  - role_permissions    : ตาราง Dynamic ACL Matrix (Role x Permission)
  - users               : ตารางบัญชีผู้ใช้งานและรหัสผ่าน Hash
  - rooms               : ตารางห้องประชุม ความจุ และอาคาร
  - room_bookings       : ตารางรายการคำขอจองห้องและสถานะ (พร้อม btree_gist Guard)
  - booking_attachments : ตารางไฟล์แนบวาระประชุมและรูปภาพตรวจสภาพห้อง
  - audit_logs          : ตารางบันทึกประวัติความปลอดภัยและการกระทำทั้งหมด
  - user_sessions       : ตาราง PostgreSQL Session Store


--------------------------------------------------------------------------------
9. SELECT * FROM <table_name>;
--------------------------------------------------------------------------------
ประเภท: SQL Query (ต้องมีเครื่องหมาย ; ปิดท้าย)
คำอธิบาย: ดึงข้อมูลและตรวจสอบความถูกต้องของข้อมูลในตาราง
คำสั่งที่แนะนำให้ใช้เปิดโชว์อาจารย์:
  SELECT username, full_name, role_name, is_active FROM users;
  SELECT booking_id, title, status, start_time, end_time FROM room_bookings;
  SELECT action, username, status, created_at FROM audit_logs ORDER BY created_at DESC LIMIT 5;

สรุปขั้นตอนการแก้ปัญหา Error 3D000 และตั้งค่า Database (ระบบ RoomReserve)
================================================================================

[ วิธีที่ 1: ทำผ่าน psql CLI แบบข้อต่อข้อ ]
1. เปิด Terminal แล้วพิมพ์เชื่อมต่อ psql:
   psql -h localhost -U postgres

2. ตั้งค่าแสดงผลภาษาไทย/UTF-8:
   \encoding UTF8

3. สร้าง Database:
   CREATE DATABASE roomreserve_db;

4. เชื่อมต่อไปยัง Database:
   \c roomreserve_db

5. รันสคริปต์สร้างตาราง:
   \i database/schema.sql

6. ออกจาก psql:
   \q

7. กลับมาที่ Terminal แล้วรันคำสั่งหยอดข้อมูลตั้งต้น (Roles, Users, Permissions):
   npm run seed

8. เริ่มรันเซิร์ฟเวอร์:
   npm start


--------------------------------------------------------------------------------
[ วิธีที่ 2: ทางลัดอัตโนมัติของ RoomReserve (Zero-Touch One Command) ]
--------------------------------------------------------------------------------
หากไม่ต้องการเข้า psql สามารถรันผ่าน PowerShell ในโฟลเดอร์โปรเจกต์ได้ทันที:

1. สั่งสร้าง Database อัตโนมัติ (แก้ Error 3D000 ทันที):
   node database/setup_db.js

2. สั่งรัน Schema + หยอดข้อมูลตั้งต้นทั้งหมดในคำสั่งเดียว:
   npm run seed

3. รันระบบ:
   npm start
